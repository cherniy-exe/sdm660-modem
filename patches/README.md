# Внимание: патч на ipa2-lite нерабочий

`0001-sdm660-ipa2-lite-modem-data-path.patch` собирается и даёт загружаемый
модуль с корректным DT-alias, но при загрузке на Redmi Note 7 (SDM660,
 Tianma) вызывает **hard LOCKUP CPU и RCU stall**; подробности —
`../docs/BRING-UP.md`.

Патч оставлен только как материал для экспериментов и отладки. Не ставьте его
на ежедневное устройство без полного бэкапа `boot.img` и модулей
(см. `../docs/ROLLBACK.md`).
